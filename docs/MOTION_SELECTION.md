# Adaptive motion-aware testing

Version 108 uses 12 two-second probes below five minutes, 20 below 30 minutes, 32 below two hours, 40 below four hours, and 48 for longer recordings. Each is randomly located within its own time stratum. Native-resolution, original-frame-rate FFmpeg vmafmotion measurements guide diversity, not quality acceptance. The highest-motion probe is always retained, with remaining choices spread across time and several motion quantiles. This is not a whole-file average or a measure of spatial detail.

Initial search coverage is six eight-second clips below one hour and eight for longer files, reduced to floor(duration/16) on short files to leave room for holdouts. Files up to 30 seconds use the entire file. Overlapping search clips are rejected. With no motion filter, time-distributed clips and the same independent quality checks are used; no motion values are claimed.

Selected clips are concatenated into an FFV1 reference without another lossy generation, preserving source-relative frame timing within each clip. ab-av1 crf-search searches that reference with the requested XPSNR target. Its size/time estimate is rescaled by original/reference duration; no minimum savings threshold applies.

After the search, the exact proposed encoder, preset and quantizer are used through the final-output command builder to encode each search clip and 2–4 nonoverlapping held-out clips (less if there is insufficient remaining footage). Each clip is independently XPSNR-scored after frame-count and timestamp alignment checks. The lowest color-plane XPSNR summary is used. Every checked clip must meet the user's target. These are clip averages, not per-frame quality floors.

One held-out clip is reserved outside every search reference. Other holdouts can be promoted into an expanded reference; new clips are selected from unused probes, or the largest uncovered time intervals if needed. Candidate failures tighten the next ab-av1 search's maximum CRF/CQ/ICQ and raise its search target according to the observed deficit; Archiver still uses ab-av1's search, not a fixed quality grid. The user's acceptance target does not change.

Additional rounds are triggered by failed clip checks, XPSNR spread above 3 dB, clip encoded-byte-rate ratio above 2, or successive full-size estimate changes above 10%. These are engineering thresholds, not validated perceptual or statistical limits. Up to four search rounds are allowed. This bounds repeated sample work, not elapsed time. A failed clip after the expansion budget produces no applicable result; successful but variable results clearly warn that size estimates have limited reliability. No sample-based workflow guarantees unseen sections.

Within a job, matching clip/encoder/quantizer checks and lossless clip references are reused. No global result is reused across changed sampling-policy fingerprints. The test folder contains motion-selection.json, raw motion statistics, round-N search artifacts, checks/, reference-clips/, validation-history.json and results.json. Failed or cancelled runs retain diagnostics; they do not enqueue encoding settings. Temporary work can be large, especially for high-resolution FFV1 references.

The main result retains the combined search XPSNR and estimated video-only output size, and also reports the lowest checked clip. Test details list each clip's location, search/independent role, XPSNR and pass/fail outcome. Apply settings and review opens Manual controls without starting encoding. Preview proxy cache names include source window timestamps and durations so changing sample indices cannot serve stale footage.

Validation includes stratified coverage, strongest-motion retention, nonoverlapping holdouts, sample-budget boundaries, per-clip rejection despite a passing combined score, adaptive expansion, cache reuse, cancellation and short full-file coverage. A real 96-second synthetic 320×180/12-fps H.264 test exercised FFmpeg, ab-av1 and individual XPSNR checks. These checks establish pipeline behavior, not calibration on real gameplay.
